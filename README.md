# Coach Assistant Platform (پلتفرم دستیار هوشمند مربی و آکادمی ورزشی)

یک پلتفرم ماژولار، مقیاس‌پذیر و پایدار برای مدیریت جامع مربیان ورزشی (تنیس و سایر ورزش‌ها)، شاگردان، تقویم و سانس‌های زمین، امور مالی و شهریه، برنامه‌های تمرینی، درگاه پرداخت آنلاین، کیف پول مربی و دستیار هوش مصنوعی.

---

## 🏗️ معماری کلان ماژولار (Modular Apps Architecture)

پروژه به صورت برنامه‌ها و سرویس‌های مجزا (Modular Monolith) با مرزبندی مشخص پیاده‌سازی شده است:

### اپلیکیشن‌های فعال (Core Apps):
1. **`identity_profile`:** احراز هویت با OTP و توکن‌های JWT، مدیریت کاربران، مربیان و پروفایل.
2. **`coach_portal`:** داشبورد تحلیلی مربی، آمار درآمد ماهانه و سالانه، سانس‌های امروز و اعلانات.
3. **`student_portal`:** داشبورد اختصاصی شاگرد، کلاس‌ها، جلسات رزرو شده، و مربیان مرتبط.
4. **`student_management`:** ثبت شاگرد، سیستم دعوت‌نامه پیامکی/لینکی، و روابط چندمربی (`CoachStudentRelationship`).
5. **`scheduling_classes`:** کلاس‌های خصوصی/گروهی، ترم‌های دوره‌ای/ماهانه، جلسات، حضور و غیاب، و تقویم شمسی.
6. **`finance_billing`:** بدهی‌ها، پرداخت‌ها، تسهیم هزینه زمین و درآمد مربی، صورت‌حساب، و تسویه با معماری مقاوم در برابر خطای داده‌های قدیمی (Defensive Payment Engine).
7. **`training_programs`:** بانک تمرین‌ها و طراحی برنامه‌های تمرینی تخصصی شاگردان.
8. **`notifications`:** سرویس اعلان‌های درون‌برنامه‌ای و ارسال پوش نوتیفیکیشن.

### اپلیکیشن‌های توسعه‌پذیر آینده (Future-Ready Modules):
9. **`payments_gateway`:** ماژول مستقل درگاه پرداخت آنلاین شاگرد با پشتیبانی از درگاه‌های شتابی (مانند زرین‌پال و شپا) و ثبت خودکار پرداخت در سوابق مالی.
10. **`coach_wallet`:** کیف پول داخلی مربی، گردش حساب، ثبت شبای بانکی و درخواست‌های تسویه/نقد کردن موجودی.
11. **`ai_engine`:** موتور هوش مصنوعی برای تولید هوشمند برنامه‌های تمرینی اختصاصی و تحلیل عملکرد ورزشی شاگردان.

---

## 🛡️ رفع ریشه‌ای خطای ثبت پرداخت در داده‌های گذشته
در این معماری، لایه مالی به صورت **Fail-Safe** طراحی شده است:
- کلاس‌های حذف شده یا نامعتبر مانع ثبت پرداخت شاگرد نمی‌شوند.
- اقلام بدهی کدهای قبلی بدون کلاس با عنوان «سوابق قبلی / جلسات آزاد» دسته‌بندی می‌شوند تا از خطای ۴۰۴ جلوگیری شود.
- اسکریپت تعمیر و سلامت‌سنجی پایگاه داده در مسیر `backend/scripts/repair_legacy_data.py` قرار دارد.

## 🚀 راهنمای راه‌اندازی سریع

### ۱. اجرای بک‌اند (Backend):
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

### ۲. بررسی و تعمیر داده‌های قدیمی دیتابیس:
```bash
python scripts/repair_legacy_data.py
```

### ۳. اجرای فرانت‌اند موبایل (React Native / Expo):
```bash
cd mobile
npm install
npm run start
```
