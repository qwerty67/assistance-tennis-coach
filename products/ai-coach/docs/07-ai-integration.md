# 🤖 یکپارچه‌سازی هوش مصنوعی - TennisPilot (خلاصه)

**مدل:** Qwen3-30B-A3B  
**ارائه‌دهنده:** ArvanCloud AI  
**کاربرد:** تولید گزارش‌های تحلیلی فارسی و دیسیپلین‌محور از مسابقات تنیس

---

## ️ راه‌اندازی

1. دریافت API Key از پنل ArvanCloud.
2. قرار دادن کلید در فایل `backend/.env`:
   ```env
   ARVAN_API_KEY=your_api_key_here
   ```
3. تنظیمات کلاینت در `backend/app/services/ai_service.py`.

---

## 📡 Endpoint های مرتبط

| متد | مسیر | توضیحات |
|-----|------|---------|
| `POST` | `/matches/{id}/analyze` | اجرای تحلیل AI و **ذخیره خودکار** در دیتابیس |
| `GET` | `/matches/{id}/analysis/latest` | دریافت آخرین تحلیل ذخیره‌شده (بدون هزینه API) |
| `GET` | `/matches/{id}/analyses` | دریافت تاریخچه کامل تحلیل‌های یک مسابقه |

---

## 🔄 جریان کار (Workflow)

1. **بررسی کش:** ابتدا `GET /analysis/latest` صدا زده می‌شود.
2. **تحلیل جدید:** اگر تحلیلی نبود، `POST /analyze` فراخوانی می‌شود.
3. **پردازش AI:** مدل Qwen3 داده‌ها را گرفته و گزارش Markdown تولید می‌کند.
4. **ذخیره‌سازی:** نتیجه در جدول `analyses` دیتابیس ذخیره می‌شود.
5. **نمایش:** فرانت‌اند گزارش را نمایش داده و بنر "از کش" را نشان می‌دهد.

---

## 📝 ساختار پرامپت (Prompt)

- **نقش:** مربی حرفه‌ای تنیس با لحن سخت‌گیر و داده‌محور.
- **خروجی:** فرمت Markdown شامل ۴ بخش اصلی:
    1. کالبدشکافی جریان بازی
    2. نقاط قوت تاکتیکی
    3. نقاط ضعف بحرانی
    4. پروتکل تمرینی اختصاصی

---

##  هزینه‌ها

- **بسیار مقرون‌به‌صرفه:** حدود **0.015 تومان** برای هر تحلیل کامل.
- **بهینه‌سازی:** با استفاده از سیستم کش، هزینه‌ها به حداقل می‌رسد.

---

## ✅ Best Practices (نکات کلیدی)

- [ ] **همیشه اول کش را چک کنید** تا از هزینه‌های تکراری جلوگیری شود.
- [ ] **تاریخچه را نگه دارید** تا مربی بتواند تحلیل‌های مختلف را مقایسه کند.
- [ ] **Loading State مناسب** نمایش دهید (چون تولید گزارش ۱۰ تا ۲۰ ثانیه طول می‌کشد).
- [ ] **Error Handling** قوی برای خطاهای شبکه یا API Key داشته باشید.
- [ ] **حداقل داده:** برای تحلیل معنادار، مسابقه باید `completed` و حداقل ۵ امتیاز ثبت شده باشد.

---

##  عیب‌یابی سریع

- **خطای Model not found:** نام مدل را در `ai_service.py` چک کنید (گاهی نیاز به `metricKey` دارد).
- **گزارش خالی:** مطمئن شوید مسابقه `completed` است و امتیازات کافی ثبت شده‌اند.
- **خطای API Key:** فایل `.env` و بارگذاری آن توسط `python-dotenv` را بررسی کنید.
