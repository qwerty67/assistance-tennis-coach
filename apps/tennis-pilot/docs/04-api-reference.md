# 📡 مستندات API - TennisPilot (خلاصه)

**Base URL:** `http://localhost:8000`  
**فرمت پاسخ:** JSON  
**مستندات تعاملی (Swagger):** `http://localhost:8000/docs`

---

## 🧑‍ شاگردان (Students)

| متد | مسیر | توضیحات |
|-----|------|---------|
| `GET` | `/students/` | لیست همه شاگردان + آمار کلی |
| `POST` | `/students/` | ایجاد شاگرد جدید |
| `GET` | `/students/{id}` | اطلاعات پایه یک شاگرد |
| `GET` | `/students/{id}/details` | جزئیات کامل + آمار دقیق (On-the-fly) |
| `PUT` | `/students/{id}` | ویرایش اطلاعات شاگرد |
| `DELETE` | `/students/{id}` | حذف شاگرد (همراه با Cascade) |

---

## 🎾 مسابقات (Matches)

| متد | مسیر | توضیحات |
|-----|------|---------|
| `GET` | `/matches/` | لیست همه مسابقات |
| `POST` | `/matches/` | ایجاد مسابقه جدید |
| `GET` | `/matches/{id}` | جزئیات مسابقه |
| `PUT` | `/matches/{id}` | ویرایش مسابقه |
| `POST` | `/matches/{id}/complete` | تکمیل مسابقه (ثبت نتیجه نهایی) |
| `GET` | `/matches/{id}/statistics` | آمار ریز مسابقه |

---

## 📊 امتیازات (Points)

| متد | مسیر | توضیحات |
|-----|------|---------|
| `GET` | `/matches/{id}/points` | لیست امتیازات یک مسابقه |
| `POST` | `/matches/{id}/points` | ثبت امتیاز جدید |
| `DELETE` | `/matches/{id}/points/{point_id}` | حذف امتیاز (Undo) |

---

## 🤖 تحلیل هوش مصنوعی (AI Analysis)

| متد | مسیر | توضیحات |
|-----|------|---------|
| `POST` | `/matches/{id}/analyze` | تحلیل با AI + ذخیره خودکار در دیتابیس |
| `GET` | `/matches/{id}/analysis/latest` | دریافت آخرین تحلیل ذخیره‌شده (بدون هزینه AI) |
| `GET` | `/matches/{id}/analyses` | تاریخچه تمام تحلیل‌های مسابقه |

---

## ⚙️ نکات کلیدی

- **احراز هویت:** در حال حاضر غیرفعال است.
- **کدهای خطای رایج:**
    - `400`: داده‌های نامعتبر (Validation Error)
    - `404`: منبع پیدا نشد (Not Found)
    - `500`: خطای داخلی سرور
- **محدودیت AI:** برای تحلیل، مسابقه باید `completed` باشد و حداقل ۵ امتیاز ثبت شده باشد.
- **مدیریت Schema:** در صورت تغییر ساختار جداول، فایل `tennis.db` را حذف و بک‌اند را ری‌استارت کنید.
